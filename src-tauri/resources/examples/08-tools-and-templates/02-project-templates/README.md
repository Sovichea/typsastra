# Project templates

This exercise uses the project-creation workflow rather than a Typst source
file.

## Try it

1. Open **Create New Project** from the welcome screen or the application menu.
2. Browse **Typst Universe** for an online template, or open the **Downloaded**
   and **User** tabs.
3. Preview a template, choose a project name and location, and create the
   project.
4. Open the generated project and confirm that it is an ordinary multi-file
   Typst workspace.
5. Create a blank project for comparison.
6. Save an existing project as a user template, then create another project
   from that saved template.

Template archives are portable `.typsastra` projects. They exclude font
binaries, generated PDFs, preview caches, and recovery snapshots. A recipient
must install any required fonts separately.

Online template browsing needs network access. Downloaded and user templates
remain available offline.

Tutorial: <https://docs.typsastra.com/tutorials/PROJECT_TEMPLATES/>
