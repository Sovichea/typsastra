# Tools and templates

This section covers project-owned visual tools and the workflows that create a
new project.

## Exercises

- `01-linked-table`: recover or create a Table Tools model, link it to a
  `//@table:` anchor, edit the grid, and inspect the generated Typst block.
- `02-project-templates/README.md`: browse Typst Universe, downloaded, and user
  templates; create a project; and save a reusable user template.
