# Typsastra README project

Set `main.typ` as the main file. This project combines a template, imported
metadata, included chapters, bibliography data, and image assets. It is intended
to verify ordinary research-project relationships rather than language tools in
isolation.

It also serves as a realistic preview and navigation exercise:

- switch between Normal and Draft Preview, then hover the wordmark, icon, and
  chapter figure placeholders;
- use `Alt+Enter` or `Option+Enter` from source and normal preview clicks for
  bidirectional navigation;
- hold `Ctrl` or `Command` inside the preview to reveal bibliography and
  internal references;
- inspect the Latin and Khmer language assignments in Document Typography.

Tutorial: <https://github.com/Sovichea/typsastra/blob/main/docs/tutorials/PROJECTS_AND_MAIN_FILES.md>
