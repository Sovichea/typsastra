# Editor workflows

This section covers the project-level editing workflows that keep a long
document coherent: search and replacement, recovery, the shared main-document
outline, source history, and document-language settings.

## Exercises

- `01-project-search-and-recovery`: search a three-file notebook with literal,
  regex, and fuzzy modes; review a cross-file replacement; inspect unsaved-work
  recovery; follow the shared outline; and retrace source jumps with Back and
  Forward.
- `02-language-defaults`: compare per-project script-language assignments with
  the global defaults used by new projects. The document includes English,
  Khmer, French, and Arabic samples without requiring optional dictionaries.

## Suggested order

1. Finish `05-project-portability/01-main-and-included-files` so the main-file
   model is familiar.
2. Open `01-project-search-and-recovery/main.typ` and work through its README.
3. Open `02-language-defaults/main.typ` and compare its project assignments with
   **Settings → Language → Default document languages**.
