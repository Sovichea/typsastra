# Preview and media

This section covers the live preview, image-heavy authoring, and the visual
tools that work beside it.

## Exercises

- `01-draft-preview-and-image-guidance`: switch between Normal and Draft
  preview, inspect cached image thumbnails, follow image diagnostics, and review
  an optimized copy in Image Tools.
- `02-image-helper-chains`: click an image rendered through nested helper
  functions and confirm that inverse sync selects the outermost call. The same
  call becomes the Draft Preview placeholder.
- `03-preview-navigation`: use manual forward sync, inverse sync, internal
  references, external links, page jumps, and preserved scroll position.
- `04-private-local-fonts`: configure a machine-local font directory, inspect
  font fallback order, and review the project-export boundary.
- `05-markdown-notes/README.md`: open a Markdown note for sanitized live
  preview, common GFM structures, workspace resources, mixed scripts, and
  blocked remote content.
