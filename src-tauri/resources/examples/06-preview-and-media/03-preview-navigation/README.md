# Preview navigation

This example contains both internal Typst references and external links.

## Try it

1. Put the cursor in a rendered source paragraph and trigger manual forward
   sync with `Alt+Enter` or `Option+Enter`.
2. Click rendered text normally to inverse-sync to source.
3. Hold `Ctrl` or `Command` inside the preview to reveal clickable references.
4. Follow the internal reference and compare its highlight with the web and
   email links.
5. Enter page `2` in the preview toolbar, then use the floating first-page
   button.
6. Scroll to the middle, recompile, and confirm that the scroll offset is
   restored rather than resetting to page one.

Tinymist currently resolves forward sync to the source line. Exact horizontal
word positioning is not available from its PDF source-map response.
